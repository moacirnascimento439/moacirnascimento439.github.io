Meu site de portfólio como **Desenvolvedor Front-end**, feito com **HTML, CSS e JavaScript puro**.

## ✨ Recursos
- Layout responsivo com menu "hambúrguer" no celular
- Tema claro/escuro: segue o sistema e lembra a escolha (`localStorage`)
- Destaque no menu da seção visível e animação ao rolar (`IntersectionObserver`)
- Acessibilidade: link "pular para o conteúdo", foco visível, `aria-expanded` no menu e respeito a `prefers-reduced-motion`
- Prévia bonita ao compartilhar o link (meta tags Open Graph)
- 6 testes E2E com Playwright, rodando no GitHub Actions
